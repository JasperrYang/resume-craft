## 一、产品定位

**一句话定位**：基于真实经历的简历精修工具——不编造，只翻译。

**核心理念**：用户已有好食材（真实经历）+ 我们的菜谱（JD要求）= 做出一道好菜（针对性简历）

**产品形态**：微信小程序

---

## 二、目标用户

### 核心用户画像

| 维度 | 描述 |
|------|------|
| 人群 | 社招/跳槽/转行人群（1-10年工作经验） |
| 年龄 | 24-35岁 |
| 痛点 | 简历和JD不匹配，投递后石沉大海 |
| 场景 | 看到心仪岗位，需要快速定制简历 |
| 消费能力 | 愿意为效果付费，单次几元可接受 |

### 非目标用户（MVP阶段）

- 应届生（经历少，容易陷入编造陷阱）
- 高管/猎头场景（需要更深度的定制服务）

## 三、MVP 功能规划

### 3.1 核心功能模块

| 优先级 | 功能模块 | 用户操作 | 后台逻辑 | 解决痛点 |
|--------|---------|---------|---------|---------|
| P0 | 事实库建立 | 上传PDF/Word旧简历 | OCR解析 + 结构化提取，建立"用户能力库" | 确保内容真实，不瞎编 |
| P0 | JD对标 | 粘贴招聘JD文本或链接 | NLP分析JD关键词（技能、职责、要求） | 识别HR想看什么 |
| P0 | 智能改写 | 点击"一键优化" | 用"能力库"素材回答JD需求，STAR法则改写 | 提高匹配度，通过ATS |
| P0 | 匹配度报告 | 查看评分 | 优化前后匹配度对比 + 缺失项提醒 | 给用户信心 |
| P0 | 对话式调整 | 聊天式输入修改意见 | AI理解意图，局部改写，实时更新 | 精准微调 |
| P0 | 导出 | 导出PDF / 复制文本 | 生成ATS友好的简洁PDF | 直接投递 |
| P0 | 微信支付 | 购买次数包 | 微信支付API v3 | 商业闭环 |
| P1 | JD链接抓取 | 粘贴招聘链接 | 后端抓取页面解析JD | 降低输入成本 |
| P1 | 简历手动录入 | 表单填写 | 直接生成结构化数据 | OCR解析不准时的备选方案 |

## 五、交互设计要点

### 5.1 设计风格

- **主色调**：深蓝(#1A56DB) + 白(#FFFFFF) + 浅灰(#F3F4F6)
- **辅助色**：成功绿(#059669) / 警告橙(#D97706) / 强调紫(#7C3AED)
- **风格**：简洁专业，避免花哨动效，杜绝AI味设计
- **字体**：系统默认字体，正文14px，标题16-20px
- **圆角**：8px统一圆角
- **参考产品**：脉脉、猎聘、Boss直聘的专业感

### 5.2 对话式调整交互规范

**布局**：上方为简历预览（可折叠），下方为对话区域

**AI回复规范**：
1. 每次调整后展示 diff（标绿=新增，标红=删除）
2. 必须提供 [应用修改] 和 [撤销] 按钮
3. 涉及事实数据变更时弹出确认提醒
4. 每次调整后实时更新匹配度评分

**预设快捷操作**（底部chip标签）：
- "更简洁" / "更详细" / "更正式" / "突出管理能力" / "突出技术深度"

## 六、商业模式

### 6.1 付费策略（按次付费为主）

| 产品 | 价格 | 包含内容 | 说明 |
|------|------|---------|------|
| 免费体验 | ¥0 | 每日1次匹配度分析（仅看评分，不看改写） | 引流转化 |
| 单次优化 | ¥3.9 | 1次完整改写 + 3轮对话调整 + PDF导出 | 尝鲜用户 |
| 5次包 | ¥14.9 (¥2.98/次) | 5次完整优化 | 活跃求职者 |
| 20次包 | ¥49.9 (¥2.50/次) | 20次完整优化 | 重度用户 |

**为什么不做月卡无限次**：
- AI token 成本按次计费，每次改写约消耗 0.3-0.8 元 token
- 无限次模式下重度用户会导致亏损
- 按次付费更符合"低频高焦虑"的求职场景

### 6.2 对话调整次数策略

- 单次优化包含 **3轮免费对话调整**
- 超出3轮后每轮 ¥0.5（从已购次数包中扣减）
- 避免用户无限对话导致 token 成本失控

### 6.3 营收预估（保守）

```
假设：
- 月活用户 5000人
- 付费转化率 8%（400人）
- 平均客单价 ¥10
- 月营收 = 400 × 10 = ¥4,000
- AI成本 = 400 × 3次 × ¥0.5 = ¥600
- 服务器成本 ≈ ¥200/月
- 毛利 ≈ ¥3,200/月 (80%)
```

## 七、风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| AI改写失真 | 高 | 严格约束Prompt，只基于事实库改写，缺失项诚实标注 |
| OCR解析不准 | 中 | 提供手动修正入口 + 手动录入备选方案 |
| 用户投诉改写质量 | 中 | 对话调整功能兜底 + 不满意可重新生成 |
| Token成本失控 | 中 | 按次付费 + 对话轮次限制 |
| 竞品模仿 | 低 | 快速迭代 + 积累用户能力库数据壁垒 |
