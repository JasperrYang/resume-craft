> 版本：v1.0 MVP

## 一、技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | 微信小程序原生 (WXML + WXSS + TypeScript) | 官方原生，稳定可控 |
| 后端 | Python 3.11+ / FastAPI | 异步框架，AI集成友好 |
| 数据库 | MongoDB (腾讯云MongoDB) | 文档数据库，灵活存储简历结构化数据 |
| 文件存储 | 腾讯云 COS | 存储用户上传的简历文件和生成的PDF |
| AI 能力 | 腾讯云智能体开发平台 | 简历解析、JD分析、智能改写 |
| OCR | 腾讯云文字识别 OCR | 解析PDF/图片简历 |
| 服务器 | 腾讯云 Lighthouse | 轻量应用服务器，性价比高 |
| 支付 | 微信支付 API v3 | 小程序内支付 |
| 部署 | Docker + Nginx | 容器化部署 |
| 监控 | 腾讯云监控 + 应用日志 | 基础运维 |

## 五、AI Prompt 策略（核心）

### 5.1 简历结构化提取 Prompt

```
角色：你是一个简历解析专家。

任务：将以下OCR识别的简历文本，解析为结构化JSON格式。

要求：
1. 严格基于原文提取，不添加任何不存在的信息
2. 无法识别的字段标记为 null
3. 技能关键词尽量拆分为独立项

输出JSON格式：
{
  "basic_info": { "name", "phone", "email", "location" },
  "education": [{ "school", "degree", "major", "start_date", "end_date" }],
  "experience": [{
    "company", "title", "start_date", "end_date",
    "description", "keywords": [], "metrics": []
  }],
  "skills": [],
  "projects": [{ "name", "role", "description", "tech_stack": [] }]
}

简历原文：
{ocr_text}
```

### 5.2 JD 关键词提取 Prompt

```
角色：你是一个招聘需求分析专家。

任务：分析以下职位描述(JD)，提取关键信息。

输出JSON格式：
{
  "company": "公司名称",
  "position": "职位名称",
  "required_skills": ["必须技能"],
  "preferred_skills": ["加分技能"],
  "responsibilities": ["核心职责"],
  "requirements": ["硬性要求，如学历、年限"],
  "keywords_weight": {
    "关键词": 权重(1-10)
  }
}

JD原文：
{jd_text}
```

### 5.3 智能改写 Prompt（核心，产品灵魂）

```
角色：你是一个资深简历优化师。你的原则是"绝不捏造经历，只做精准翻译"。

背景：
- 用户正在申请一个新职位
- 你需要基于用户的真实经历，针对目标JD进行简历优化

输入：
1. 用户简历结构化数据：{resume_data}
2. 目标JD分析结果：{jd_analysis}

改写规则（严格遵守）：
1. 【绝对禁止】编造用户没有的经历、技能、项目
2. 【绝对禁止】虚构数据指标（如将DAU从10万改成100万）
3. 【允许】调整经历描述的侧重点，突出与JD匹配的部分
4. 【允许】使用STAR法则重新组织语言
5. 【允许】添加JD中的关键词（前提是用户确实具备该能力）
6. 【允许】调整经历排列顺序，匹配度高的排前面
7. 【必须】对JD要求但用户缺失的能力，标注为"缺失项"
8. 【必须】每处改动标注改动原因

输出JSON格式：
{
  "optimized_sections": [{
    "section": "工作经历-XX公司",
    "original": "原文",
    "optimized": "改写后",
    "reason": "改动原因",
    "matched_keywords": ["匹配到的JD关键词"]
  }],
  "match_score": {
    "before": 40,
    "after": 82,
    "details": {
      "skills_match": 75,
      "experience_match": 80,
      "keyword_match": 90
    }
  },
  "missing_items": [{
    "requirement": "JD要求",
    "suggestion": "建议（如果无法匹配则诚实说明）"
  }],
  "full_resume_text": "完整的优化后简历文本"
}
```

```
角色：你是简历优化师，正在帮用户微调简历。
```

## 六、安全设计

### 6.1 数据安全

| 措施 | 说明 |
|------|------|
| 传输加密 | 全链路HTTPS，小程序强制要求 |
| 数据加密 | 用户手机号、邮箱等敏感信息AES加密存储 |
| 文件安全 | COS 私有读写，通过后端签名URL临时授权 |
| Token认证 | JWT token，有效期2小时，支持刷新 |

### 6.2 支付安全

| 措施 | 说明 |
|------|------|
| 签名验证 | 微信支付回调必须验证签名 |
| 幂等处理 | 同一通知去重，防止重复发货 |
| 金额校验 | 回调金额与订单金额必须一致 |
| HTTPS回调 | 支付回调地址必须HTTPS |

### 6.3 API安全

| 措施 | 说明 |
|------|------|
| 请求频率限制 | 单用户 60次/分钟 |
| 参数校验 | Pydantic 强类型校验 |
| SQL注入防护 | MongoDB参数化查询（非字符串拼接） |
| 文件类型校验 | 仅允许 PDF/DOCX，限制10MB |
